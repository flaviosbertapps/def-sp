# def-sp

App de apoio ao estudo para o X Concurso de Defensora ou Defensor Público do Estado de São Paulo (prova objetiva em 10/01/2027).

- `PLANEJAMENTO.md`: avaliação, riscos e cenários
- `ETAPAS.md`: etapas de desenvolvimento
- `conteudo/`: conteúdo programático extraído do edital
- `materiais/`: edital e legislação oficial (ver `materiais/LEIA-ME.md`)
- `scripts/`: extração do programa e download dos materiais
